FATIH RELOAD PROTOTYPE V2
Fitur: katalog paket berbeda, tambah/ubah paket, impor CSV ke paket terpilih, stok per paket, ekspor CSV, checkout simulasi, fondasi PWA.
Cara mencoba: ekstrak ZIP lalu buka index.html. Untuk PWA, hosting harus HTTPS lalu pilih Tambahkan ke layar utama di browser Android.
Belum untuk transaksi nyata. Data disimpan di localStorage browser. Butuh backend/database, login admin, QRIS dinamis, webhook pembayaran terverifikasi, penguncian stok atomik, dan WhatsApp Business API/provider. Jangan masukkan kode voucher sungguhan untuk operasional publik di prototipe ini.
